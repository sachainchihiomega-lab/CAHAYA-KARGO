⚠️ 1. Penyebab & Solusi Layar Masih Blank Putih:

Penyebab: Yang diupload ke public_html adalah source code mentah (terdapat folder src/ atau package.json). Server Apache cPanel tidak bisa mengeksekusi TypeScript/React mentah tanpa dibundle.

Solusinya: Unduh file ZIP siap pakai mitrakargo_cpanel_siap_pakai.zip di bawah, lalu ekstrak langsung isinya ke dalam folder public_html. Website akan langsung aktif dan sempurna!

⚠️ 2. Penyebab & Solusi Error Database Import:

Penyebab: Muncul error "No database selected" atau charset mismatch karena tab "Import" diklik di halaman awal server phpMyAdmin sebelum memilih nama database.

Solusinya: Di cPanel, buat dulu databasenya (misal: mitr3369_kargo). Lalu di phpMyAdmin, KLIK nama database tersebut di sebelah kiri sampai terbuka, barulah klik tab Import!

Langkah Praktis Deploy (5 Menit Selesai):

1

Bersihkan File Lama di public_html

Buka cPanel (https://manaslu.rumahweb.com:2083), login dengan user mitr3369. Masuk ke File Manager lalu klik folder public_html. Hapus file mentah yang diupload sebelumnya (seperti src/, package.json, atau file placeholder default Rumahweb).

2

Upload & Ekstrak mitrakargo_cpanel_siap_pakai.zip

Di dalam folder public_html, klik tombol Upload di toolbar cPanel. Pilih berkas mitrakargo_cpanel_siap_pakai.zip. Setelah 100% hijau, kembali ke File Manager, klik kanan pada file zip tersebut lalu pilih Extract. File index.html, folder assets/, dan file .htaccess akan berada langsung di root public_html.

3

Buat Database di Menu "MySQL® Databases" cPanel

Di cPanel, cari menu MySQL® Databases. Buat database baru (misal diberi nama mitr3369_kargo). Buat user MySQL baru (misal mitr3369_user). Di bagian "Add User To Database", pilih user dan databasenya, centang ALL PRIVILEGES, lalu klik Make Changes.

4

Impor File database_mitrakargo.sql di phpMyAdmin

Kembali ke halaman utama cPanel, klik menu phpMyAdmin. WAJIB: Di kolom sebelah kiri, klik nama database Anda (mitr3369_kargo). Setelah nama database terbuka, klik tab Import di bar atas, pilih file database_mitrakargo.sql, lalu klik tombol Go / Kirim di bagian bawah. Seluruh 8 tabel & data siap pakai langsung terpasang tanpa error!

5
